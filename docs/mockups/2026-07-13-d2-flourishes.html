補完 D2 = 三樣(只加在有意義的卡,不是每張)
  • tab-strip 表頭:多視圖卡的頁籤做進表頭(底線高亮)—— 主要是「編出的查詢」卡(Compiled SQL / Canonical),取代現在 body 裡的按鈕對。需求:SectionCard 讓 collapsible 與 tabs 併存(加一段:collapsible 時 tab-strip 前置一個 chevron)。
  • gold fragment bar:輸出卡頂一條金色狀態條(如「WHERE clause · N params」/ 編譯狀態)—— 最像 studio 的一眼識別,成本低。套:6 個 filter builder 的輸出、2 個 generator 的輸出、decision-table 的求值結果。
  • dashed 次級容器:把 FilterTreeEditor 的畫布容器改虛線框(次級/可編輯區的視覺語言)—— 套 6 個 filter builder 的 Filter Logic。
單視圖卡(SAMPLE / FIELDS / AI / DATA…)維持 solo slab,已一致、不動。真實像素以 @rfjs/web-ui token 為準。
