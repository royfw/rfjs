本輪範圍與判斷點（請確認）
  • 共用元件：table-builder / flow-builder / bpmn-viewer 全採用 ToolEyebrow / ToolTabs / SectionCard / FragmentBar；form-builder 已有外殼，補內部（palette 卡、group 表頭色調、hex→金色 primary、JSON slab 卡）。
  • 判斷 A（內容 vs 系統表頭）：使用者命名的區塊（form 的 Account/Profile 群組、submission 的 Metadata/Data）保留可讀大小寫、只對齊色調圓角；工具系統卡才用 mono 大寫 slab。
  • 判斷 B（畫布外框）：canvas 走實心 SectionCard body，不套虛線（虛線＝可編輯樹語言）。
  • 判斷 C（canvas 補 ToolIntro）：flow / bpmn 比照 reference 補「這個工具怎麼運作？」callout（需新增 i18n concepts，en + zh-TW）。
  • 不動：React Flow / bpmn-js 畫布內部（節點樣式、diagram 反白），只動外圍 chrome。既有測試全綠（roles / names / testids / aria 不變；columns-panel 標題 <p>→<h2> 需同步改該測試 selector）。
